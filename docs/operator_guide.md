# Инструкция оператора

## Запуск

Из корня проекта, Python ≥ 3.10:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m terraplan ui
```

Открыть `http://127.0.0.1:8765` — страница решения; кнопка «Открыть расчёт» ведёт на пульт оператора
`http://127.0.0.1:8765/console`, ссылка «← Страница решения» возвращает обратно. Интернет после установки не нужен: внешних шрифтов,
CDN и сервисов нет. Если порт занят: `python -m terraplan ui --port 8766`.
При запуске из другой папки указать `--root <путь-к-репозиторию>`. Остановка: Ctrl+C.

## Порядок демонстрации для жюри

1. **BASE.** Интерфейс сразу рассчитывает рекомендованный план `P2z_earth_new_zbo` в BASE.
   Вверху — статус исполнимости, лента «BASE → стресс → действие», пять KPI и график
   «Запас и обязательный резерв» с красной пунктирной линией резерва. Эталон — опубликованный расчёт P2z в BASE.
2. **Стресс без изменения решений.** Во вкладке «Сравнение» закрепить текущий расчёт как A.
   Выбрать MANDATORY_STRESS и рассчитать B. Обзор сразу краснеет: дефицит 95,917 т,
   нехватка резерва 55,295 т, график показывает обвал запаса и красную зону 2038–2040.
   Сравнение показывает русские итоги «B − A» и таблицу по годам. Нарушения RESERVE_45D
   относятся к 2038–2040; сервис показан отдельно от жёстких ограничений.
3. **Адаптация.** Открыть `P2z_earth_new_zbo_adapted`, оставить MANDATORY_STRESS и пересчитать.
   Жёстких нарушений нет, график снова зелёный. Этот план не следует считать универсальным
   для BASE: увеличенные заказы могут вызвать переполнение хранилища.
4. **Редактор.** Изменить объём заказа, резерв мощности, инвестицию или начальный запас во
   вкладке «Решения». Для помесячного профиля ввести 12 чисел через запятую. JSON-редактор
   поддерживает массовые изменения, которые надо подтвердить кнопкой «Применить JSON».
   Попытка отрицательного заказа должна дать сообщение с полем `ordered_t`. После любой
   правки результаты помечаются «устарели» до пересчёта.
5. **Сохранение.** «Сохранить» скачивает JSON с планом, выбранным сценарием, пятью CSV
   таблицами и описанием допущений. «Открыть JSON» восстанавливает его, после чего нажать
   «Рассчитать». Поддерживается и обычный `plan.json`: он открывается на контрольных данных
   в BASE. При необходимости выбрать стресс вручную.
6. **Выгрузка.** На вкладке «Обзор» скачать XLSX либо ZIP. ZIP содержит исходный план,
   CSV/XLSX/JSON результатов, полную матрицу проверок, календарь заказов, сценарий,
   допущения, копию данных и манифест SHA-256. Скачать сравнение CSV на вкладке «Сравнение».
7. **Расширение.** Нажать «Source-X / 2041», прочитать допущения во вкладке данных,
   рассчитать. Горизонт заканчивается в 2041, появляется источник X. Демо использует
   сохранённую копию данных и сохранённый план.
8. **Параметры контрактов.** Во вкладке «Данные и контракты» менять цены, мощности, TOP,
   сроки, хранилища, инвестиции и спрос в табличных формах с числовыми полями.
   Внести смысл, единицы, диапазон и обоснование в поле допущений. Расчёт получает метку
   TEAM_COPY. BASE сохраняет жёсткие требования сервиса, MANDATORY_STRESS сохраняет
   обязательные воздействия и потолок потерь. Таблица ограничений доступна только для
   чтения в раскрывающемся CSV-блоке. «Вернуть данные» сбрасывает только копию данных;
   для контрольного расчёта также открыть исходный план.
9. **Геополитические изменения цен (дополнительный блок).** Во вкладке «Геополитика» назвать
   событие, отметить затронутые каналы, выбрать годы, ввести изменение цены в процентах (минус —
   снижение), правило сочетания с ценовым множителем сценария и обоснование. «Сравнить до и после»
   рассчитывает план с исходными ценами и с шоком и показывает разности PV, закупки, дефицита
   и сервиса; таблица эффективных цен по годам и каналам появляется ниже и выгружается в архив.
   «Вернуть исходные цены и пересчитать» отключает шок. Проверка: +25 % для Earth-Core и Earth-Flex
   в 2038–2039 для плана P2z в BASE даёт +470,892 млн PV. При сценарии MANDATORY_STRESS и правиле
   «заменяет» множитель 1,25 не начисляется повторно поверх ценовой части стресса.

## Единицы, воспроизводимость и границы

Топливо — т; мощность — т/год; деньги — млн условных единиц в постоянных ценах 2035 г.
Числа на экране округлены до 3 знаков, CSV — до 6; JSON сохраняет точность движка.
Показатель «минимальный сервис» — минимум по годам, а не среднее за горизонт.
Критический спрос входит в общий спрос. Бесконечная стоимость тонны при нулевом сервисе
отображается как «—», исходное значение остаётся в экспорте движка.

После распаковки ZIP:

```bash
python -m terraplan verify <каталог-выгрузки> --case <каталог-выгрузки>/case
```

Интерфейс предназначен для одного локального оператора. Аутентификации и общего серверного
хранилища нет. Сервер слушает только loopback, хранит последние 12 расчётов в памяти и
удаляет их при остановке. Для переноса результатов сохранить JSON/ZIP. При истечении
ссылки или закреплённого расчёта повторить расчёт. Изменённые решения отмечаются как
нерассчитанные, скачивание старого результата скрывается до пересчёта.

Методология движка и ограничения помесячного приближения описаны в приложении об архитектуре расчёта.
UI не является оптимизатором, результаты зависят от введённых решений и допущений.
