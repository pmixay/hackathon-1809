# Operator guide / Инструкция оператора

## Запуск

Из корня проекта, Python ≥ 3.10:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m terraplan ui
```

Открыть `http://127.0.0.1:8765`. Интернет после установки не нужен: внешних шрифтов,
CDN и сервисов нет. Если порт занят: `python -m terraplan ui --port 8766`.
При запуске из другой папки указать `--root <путь-к-репозиторию>`. Остановка: Ctrl+C.

## Порядок демонстрации для жюри

1. **BASE.** Интерфейс по умолчанию открывает рекомендованный R2 план `P2z_earth_new_zbo`.
   Нажать «Открыть план», выбрать BASE и «Рассчитать».
   Обзор показывает баланс и финансы, вкладка «Ограничения» — нарушения и полную матрицу.
   Эталон: `results/alternatives/P2z_earth_new_zbo_BASE/`.
2. **Стресс без изменения решений.** Во вкладке «Сравнение» закрепить текущий расчёт как A.
   Выбрать MANDATORY_STRESS, рассчитать B и сравнить. Нарушения RESERVE_45D относятся
   к 2038–2040. Дефицит и рекомендации по сервису показываются отдельно от жёстких ограничений.
3. **Адаптация.** Открыть `P2z_earth_new_zbo_adapted`, оставить MANDATORY_STRESS и пересчитать.
   Жёстких нарушений нет. Этот план не следует считать универсальным для BASE:
   увеличенные заказы могут вызвать переполнение хранилища.
4. **Редактор.** Изменить объём заказа, резерв мощности, инвестицию или начальный запас во
   вкладке «Решения». Для помесячного профиля ввести 12 чисел через запятую. JSON-редактор
   поддерживает массовые изменения, которые надо подтвердить кнопкой «Применить JSON».
   Попытка отрицательного заказа должна дать сообщение с полем `ordered_t`.
5. **Сохранение.** «Сохранить рабочий файл» скачивает JSON с планом, выбранным сценарием,
   пятью CSV таблицами и описанием допущений. «Открыть JSON» восстанавливает его, после чего
   нажать «Рассчитать». Поддерживается и обычный `plan.json`: он открывается на контрольных
   данных в BASE. При необходимости выбрать стресс вручную.
6. **Выгрузка.** На вкладке «Обзор» скачать XLSX либо ZIP. ZIP содержит исходный план,
   CSV/XLSX/JSON результатов, полную матрицу проверок, календарь заказов, сценарий,
   допущения, копию данных и манифест SHA-256. Скачать сравнение CSV на вкладке «Сравнение».
7. **Расширение.** Нажать «Демо: Source-X / 2041», прочитать допущения во вкладке данных,
   рассчитать. Горизонт заканчивается в 2041, появляется источник X. Демо использует
   `results/extensibility/case_copy/` и сохранённый план. Восстановление демо:
   `python experiments/run_extensibility.py`.
8. **Параметры контрактов.** Во вкладке «Данные и контракты» раскрыть `supply_sources.csv`
   и изменить цену, тариф резервирования или take-or-pay. Внести смысл, единицы, диапазон
   и обоснование в поле допущений. Расчёт получает метку TEAM_COPY. BASE сохраняет жёсткие
   требования сервиса, MANDATORY_STRESS сохраняет обязательные воздействия и потолок потерь.
   Таблица ограничений недоступна для изменения. «Вернуть данные кейса» сбрасывает только
   копию данных; для контрольного расчёта также открыть исходный план.

## Единицы, воспроизводимость и границы

Топливо — т; мощность — т/год; деньги — млн условных единиц в постоянных ценах 2035 г.
Числа на экране округлены до 3 знаков, CSV — до 6; JSON сохраняет точность движка.
Показатель «минимальный сервис» — минимум по годам, а не среднее за горизонт.
Критический спрос входит в общий спрос. Бесконечная стоимость тонны при нулевом сервисе
отображается как «—», исходное значение остаётся в экспорте движка.

После распаковки ZIP:

```bash
python -m terraplan verify <каталог-выгрузки> --case <каталог-выгрузки>/case
python tests/independent_recalc.py <каталог-выгрузки>
```

Интерфейс предназначен для одного локального оператора. Аутентификации и общего серверного
хранилища нет. Сервер слушает только loopback, хранит последние 12 расчётов в памяти и
удаляет их при остановке. Для переноса результатов сохранить JSON/ZIP. При истечении
ссылки или закреплённого расчёта повторить расчёт. Изменённые решения отмечаются как
нерассчитанные, скачивание старого результата скрывается до пересчёта.

Проверки: `python -m pytest -q`. Дополнительный браузерный сценарий:
`node tests/ui_smoke.cjs` при установленном Playwright и запущенном UI. По умолчанию
используется Edge; `BROWSER_CHANNEL` и `TERRAPLAN_URL` задают браузер и адрес.

Методология движка и ограничения помесячного приближения: `docs/architecture.md`.
UI не является оптимизатором, результаты зависят от введённых решений и допущений.
