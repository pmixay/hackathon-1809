Протокол теста 1 — MANDATORY_STRESS

Цель
Проверить, держит ли план P3_isru_zbo обязательные условия стресса (спрос ×1.15 с 2038, цена Earth-Core/Flex ×1.25 в 2038–2039, ISRU 55%/75% плана, потолок потерь 2%).
Варьируемый параметр
Полный пакет MANDATORY_STRESS (не изолированный параметр)
Сохраняемые условия
CAPEX, тарифы резервирования, инвестиционные решения — без изменений
Метрика
SL_total, SL_critical, 45-дневный резерв, losses/throughput
Критерий нарушения
SL_total < 0.97 (guideline в стрессе) или физический запас < R45 (hard)
Команда воспроизведения
python -m terraplan run --plan configs/plans/P3_isru_zbo.json --scenario MANDATORY_STRESS --out results/repro_stress

Протокол теста 2 — чувствительность ISRU 2038

Цель
Найти долю фактической поставки Lunar-ISRU в 2038, при которой fixed-план ещё держит ограничения
Варьируемый параметр
isru_delivery_share_2038, диапазон 0.30…1.00
Сохраняемые условия
План P3_isru_zbo фиксирован (без пересборки), прочие условия BASE
Метрика
PV cost, факт нарушения RESERVE_45D / BASE_TOTAL_SERVICE
Критерий нарушения
доля < 0.95 → дефицит 2038 превышает буфер запаса
Команда воспроизведения
python experiments/run_sensitivity.py
