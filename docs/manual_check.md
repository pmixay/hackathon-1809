# Независимая ручная проверка — план P3_isru_zbo, 2035 год, BASE

Расчёт вручную (калькулятор, без кода) против вывода движка `results/alternatives/P3_isru_zbo_BASE/`. Те же ожидаемые значения
проверяются автоматически в `tests/test_verification.py::test_manual_hand_check_2035`; пересчёт любого выгруженного каталога только по
CSV (без импорта движка) — `python tests/independent_recalc.py <каталог результатов>`.

Входы: спрос 2035 = 100 т (критический 80); базовое хранилище: потери 4,5 %, хранение 0,72 млн/т-год; Earth-Core 6,2 млн/т,
резервирование 0,45; Earth-Flex 8,9, резервирование 0,15; 45-дневный резерв R = D × 45/365.

| Шаг | Ручной расчёт | Ожидание | Движок | OK |
|---|---|---:|---:|:---:|
| R_2035 | 100 × 45 / 365 | 12,329 т | 12,329 | ✓ |
| Начальный запас (нетто) должен равняться R_2035; брутто через Earth-Flex в 2034-12 | 12,329 / (1 − 0,045) | 12,910 т брутто | 12,910 (plan.json, opening_stock) | ✓ |
| Стоимость начального запаса (учтена в 2035) | 8,9 × 12,910 + 0,15 × 12,910 | 114,90 + 1,94 = 116,84 | закупка 796,1 − 681,2 = 114,9; резерв 51,4 − 49,4 = 1,9 | ✓ |
| Целевой запас на конец 2035 = R_2036 | 140 × 45 / 365 | 17,260 т | конец 17,26 | ✓ |
| Нужное нетто-поступление | 100 + 17,260 − 12,329 | 104,931 т | — | |
| Брутто-заказ Earth-Core | 104,931 / 0,955 | 109,876 т | заказано 109,9 | ✓ |
| Потери 2035 | 109,876 × 0,045 | 4,944 т | 4,94 | ✓ |
| Закупка Earth-Core | 6,2 × max(109,876; 0,7 × 109,876) | 681,23 | 681,2 | ✓ |
| Резервирование Earth-Core | 0,45 × 109,876 | 49,44 | 49,4 | ✓ |
| Хранение (запас растёт линейно 12,33 → 17,26) | 0,72 × (12,329 + 17,260)/2 | 10,65 | 10,7 | ✓ |
| Итого 2035 | 681,23 + 114,90 + 49,44 + 1,94 + 10,65 | 858,16 | 858,2 | ✓ |
| Уровень сервиса 2035 | обслужено 100 / спрос 100 | 1,000 | 1,000 | ✓ |

Граничные проверки (см. `tests/test_boundary.py`): пустой план → дефицит = весь спрос, запас 0, отрицательного запаса нет;
100 т, поставленные в хранилище на 70 т, → STORAGE_OVERFLOW 2035-01 с превышением 30+ т; Emergency > 20 % три года подряд →
EMERGENCY_BASE_STREAK; CAPEX 1 850 к 2037 → CAPEX_2037 с превышением 50; ISRU, оплаченный в 2038-03, → INVESTMENT_TIMING и
SOURCE_NOT_AVAILABLE. Ошибочный ввод (`tests/test_invalid_input.py`): отрицательный резерв, неизвестный источник, год вне горизонта,
критический спрос выше общего, сценарий без идентификатора, некорректный JSON — каждое сообщение называет файл, поле и значение;
CLI возвращает код 3.
