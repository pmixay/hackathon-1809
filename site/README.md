# TerraPlan — презентационный сайт

> # https://terra.arbuz.lol/
>
> ### ЖИВОЙ СТЕНД — страница решения TerraPlan открыта в интернете
>
> Ничего устанавливать не нужно: откройте ссылку в браузере. Пульт оператора с расчётом
> запускается локально одной командой — `python -m terraplan ui`, затем `http://127.0.0.1:8765/console`.


Статический сайт без сборки и без зависимостей. Открывается как есть и разворачивается
на любом статическом хостинге.

## Где опубликован

**https://terra.arbuz.lol/** — рабочий адрес страницы решения (проверено 19.09.2026: HTTP 200).

Опубликована только эта страница. Пульт оператора и API (`/console`, `/api/*`) на статическом
хостинге не работают и отвечают 404 — расчёт запускается локально (`python -m terraplan ui`).

**Перед защитой страницу нужно перевыложить из этого каталога:** развёрнутая версия отстаёт от
репозитория — в ней нет кнопок «Открыть расчёт» и «GitVerse», а призыв «Откройте и проверьте сами»
в финальном блоке ни на что не ведёт. В `site/index.html` эти ссылки есть.

## Вместе с пультом оператора

`python -m terraplan ui` отдаёт эту страницу на `http://127.0.0.1:8765`, а пульт оператора —
на `/console`; кнопки «Открыть расчёт» ведут туда, ссылка «← Страница решения» возвращает обратно.
Файлы берутся из этого каталога, сборка не нужна. Если каталога `site/` рядом нет,
сервер отдаёт пульт оператора прямо на `/`, как раньше.

Из-за заголовка Content-Security-Policy на этой странице не должно быть атрибутов `style="..."`
и тегов `<style>`: оформление живёт в `assets/css/style.css`, а значения, которые считает скрипт,
ставятся через `element.style.<свойство>`.

## Локальный просмотр

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Файл `index.html` открывается и напрямую, двойным щелчком.

## Публикация

- **Netlify / Vercel / Cloudflare Pages** — перетащить папку или подключить репозиторий.
  Команда сборки не нужна, каталог публикации — корень проекта.
- **GitHub Pages** — положить содержимое папки в ветку `gh-pages` или в каталог `docs/`.
- **nginx / Apache** — скопировать папку в корень сайта.

Отдельной настройки не требуется: все пути относительные, внешних запросов сайт не делает.

## Что стоит поменять перед публикацией

- `index.html`: `<title>`, `meta name="description"`, `meta property="og:*"` — если меняется адрес сайта,
  в `og:image` лучше поставить абсолютный URL.
- `assets/img/og.jpg` — картинка для ссылок в мессенджерах, 1200×630.
- `assets/img/favicon.svg` — иконка вкладки.

## Шрифты

Montserrat распространяется по SIL Open Font License. Benzin добавлен командой;
перед публикацией стоит проверить, что лицензия допускает использование на сайте.
